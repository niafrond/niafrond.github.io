📖 Règles

🎯 Objectif : Faire deviner le plus de mots à votre équipe.


🔄 Déroulement : Chaque équipe joue à tour de rôle dans chaque manche.


📋 4 manches :

1. Libre — Description libre (sans dire le mot)

2. Un mot — Un seul mot comme indice

3. Expressions — Expression, sans les mots qui la composent

4. Pyramide — Mots dans l'ordre, sans passer


🏆 Victoire : L'équipe avec le plus de points gagne !
