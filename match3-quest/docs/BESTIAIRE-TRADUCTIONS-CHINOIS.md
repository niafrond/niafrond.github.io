# Bestiaire chinois — traductions naturelles proposées

Adaptation en **chinois simplifié** pensée comme des noms de créatures et des titres de bestiaire, plutôt qu'une traduction mot à mot. Les noms mythologiques classiques de la section B sont conservés dans leur graphie chinoise usuelle telle qu'elle figure dans le fichier source.

Colonnes : `id` et données françaises conservées ; `Nom chinois` = appellation proposée ; `Titre chinois` = adaptation du titre. Le pinyin fourni est celui du nom chinois source : il devra être recalculé pour les appellations retouchées de la section A avant intégration dans le jeu.
