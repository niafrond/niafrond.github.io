Comment jouer
  • Garde le doigt appuyé pour tirer, glisse pour déplacer le canon.
  • Chaque rangée est un mur avec un ou deux couloirs ouverts (les portes) : impossible de passer sans viser l'un d'eux.
  • Les portes ×2 ×3… multiplient les unités qui les traversent ; évite les ÷2 en visant l'autre couloir.
  • Les unités rouges qui atteignent ton canon lui font perdre des cœurs.
  • Chaque tir charge le champion : une unité géante qui se démultiplie dans les portes.
  • La base est une suite de mini-châteaux 🏰 puis un grand château final 👑 : détruis-les un par un pour gagner. ★★★ si ton canon n'a subi aucun dégât.
