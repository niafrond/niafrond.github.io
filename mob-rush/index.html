MobRush

Tire, multiplie, submerge la base adverse.

Niveaux

Pas de pièces, pas d'améliorations à acheter, pas d'énergie, pas de pub.
Uniquement ton adresse.

Comment jouer
  • Garde le doigt appuyé pour tirer, glisse pour déplacer le canon.
  • Les portes ×2 ×3… multiplient les unités qui les traversent ; évite les ÷2.
  • Les unités rouges qui atteignent ton canon lui font perdre des cœurs.
  • Chaque tir charge le champion : une unité géante qui se démultiplie dans les portes.
  • Détruis la base ennemie pour gagner. ★★★ si ton canon n'a subi aucun dégât.
